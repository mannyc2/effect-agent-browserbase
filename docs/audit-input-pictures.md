## Decisions

- Keep the separate capture connection. Actual isolated consumer Workers/CDP validation was performed by the supervisor worker; its result is `.work/evidence/consumer-workers-result.json`. Production CDP sessions stay native by default. Moving the complete fault proxy into test support fixed the Cloudflare Playwright named-event transport mismatch and removed production-only testing machinery.
- Keep per-reader sliding queues and the FIFO Stage commit queue. Effect Semaphore's immediate reacquisition probe does not establish the same ordering, and Stream.share replays chunks rather than one current frame with document/capture currency. No replacement was made without parity.
- Keep the small apart transport lifecycle and its private attachment semaphore. RcRef is optional in the report; replacing it would still need explicit event-driven end state, capture loss delivery and scoped invalidation. No saving or parity claim is made for that proposal.
- Keep performed key schedules under a policy. Plain guarded typing can insert text atomically; performed typing preserves key timing and rechecks focus before each key. The existing focus/Space policy regression remains meaningful and passes after restoring this distinction.
- A Stage has one owning clock identity. There is no public mapping between unrelated host clock domains. Refusing a mixed clock is a routine invariant, not a product approval decision.
- Keep the single `shown` style capability for the existing behavior bundle. No caller establishes a need to independently combine field focus, wheel visibility and out-of-view target scrolling; adding independently configurable modes would enlarge the contract.
- Viewport measurement remains optional capture evidence: a busy or unmeasurable viewport falls back to native device size, while capture protocol/packet failures remain failures.

## T3 owned fault seam

`internal/page/port.ts` supplies private scoped hooks for session creation, sends, stable operation/script identity and native key/navigation operations. No paid service, raw public Playwright access or expression-text matching is needed. `test/support/TestCdp.ts` owns the CDPSession proxy, named events, scoped native fixture registry and deterministic rules: hold, delay, fail, drop, reply, transform and event injection. Rule duration uses the owning Clock, gates/observation use Deferred, and rule state belongs to the test scope. Native page/context handles remain test-owned and support honest DOM assertions after the public raw access cutover. Existing live mutations and expression-text rules in browser tests were migrated to this seam. `TestCdp.test.ts` exercises method/session selection, gate cancellation, restoration and native event injection. Browser-wide request interception uses the same owned session adapter with `channel:"browser"`; its creation retains the native bound and late-detach behavior. No browser test mutates native CDP creation/send/input methods.
